1) INTRODUCCION GENERAL
================================================================================

Sigma LLM es una plataforma de inteligencia artificial orientada a personas que
necesitan resolver tareas reales con rapidez, calidad y contexto. No es solo
"un chat"; es un entorno de trabajo que combina modelos de lenguaje, analisis
multimodal, busqueda web en tiempo real y procesamiento de documentos para
convertir una pregunta en una respuesta util, accionable y clara.

El proyecto nace desde una filosofia concreta: acercar capacidades avanzadas de
IA a cualquier usuario, sin complicaciones innecesarias y con una experiencia
moderna, fluida y humana.

Sigma LLM no pretende prometer "magia". Pretende algo mas serio:
- ayudarte a pensar mejor,
- ejecutar mas rapido,
- y tomar decisiones con mejor informacion.

2) QUE ES SIGMA LLM

7) COMO FUNCIONA SIGMA LLM (ARQUITECTURA Y FLUJO)
================================================================================

Sigma LLM funciona como una capa inteligente de orquestacion:

1. Entrada del usuario
   El usuario escribe una consulta o adjunta imagen/documento.

2. Enriquecimiento de contexto
   Segun el caso, la plataforma puede:
   - analizar imagenes,
   - procesar documentos,
   - extraer contenido de URLs,
   - consultar busqueda web.

3. Enrutamiento al modelo adecuado
   Se selecciona el modelo mas conveniente segun el tipo de tarea y
   configuraciones del usuario.

4. Generacion y streaming
   La respuesta se genera y se muestra de forma progresiva para una experiencia
   rapida y natural.

5. Persistencia y continuidad
   El historial de chat se guarda para mantener contexto y trazabilidad.

Tecnologias principales (alto nivel):
- Frontend y backend sobre Next.js.
- Integracion de modelos via OpenRouter.
- Persistencia y autenticacion con Supabase y soporte de MySQL.
- Busqueda y extraccion web con proveedores especializados.
- Modulo multimodal para imagenes y PDFs.

8) MODELOS DISPONIBLES Y SUS USOS
================================================================================

Actualmente Sigma LLM integra diferentes perfiles de modelo para optimizar
resultado, costo y latencia.

A) Sigma LLM
- Perfil: modelo general de alta capacidad.
- Uso recomendado: conversaciones complejas, analisis profundos, explicaciones
  completas, asistencia integral.

B) Sigma LLM Mini
- Perfil: rapido y eficiente.
- Uso recomendado: tareas de respuesta breve, consultas frecuentes, interaccion
  agil para usuarios invitados o flujos de alta velocidad.

C) Sigma LLM Coder
- Perfil: orientado a desarrollo de software.
- Uso recomendado: escribir codigo, depurar errores, refactorizar, documentar,
  diseñar arquitectura de aplicaciones.

D) Sigma Vision
- Perfil: multimodal (analisis visual/documental).
- Uso recomendado: interpretar imagenes, extraer texto de capturas o documentos,
  describir elementos visuales y apoyar respuestas sobre contenido adjunto.

Nota editorial:
El catalogo puede evolucionar con el tiempo para incorporar modelos nuevos,
mejor rendimiento y mejor disponibilidad.
